### حالات الطلب

### تدفق الدفع

```
الطالب → إضافة للسلة → صفحة الدفع → Paymob Pixel
→ Webhook → BullMQ Worker → تحديث الطلب + إنشاء التسجيل → صفحة النجاح
```

### Workers

```bash
pnpm worker:order-completed        # تنفيذ الطلب بعد الدفع
pnpm worker:reconcile              # جدولة تسوية المدفوعات
pnpm worker:reconcile-consumer     # معالجة طابور التسوية
pnpm worker:ai-cost-aggregation    # تجميع تكاليف الذكاء الاصطناعي
```

### ✅ يعمل بالكامل اليوم

- إنشاء دورة من الأدمن

- توثيق API
